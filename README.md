# Momentos que me formaron

Línea de tiempo interactiva de hitos de aprendizaje técnico — Napoleón López.

Construida con React, Vite, TypeScript, Tailwind CSS y shadcn/ui. Desplegada en GitHub Pages vía GitHub Actions.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Despliegue

Cada push a `main` dispara el workflow `.github/workflows/deploy.yml`, que compila el proyecto y lo publica en GitHub Pages automáticamente.
